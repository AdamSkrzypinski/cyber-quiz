# 🔒 Quiz: Ochrona Danych i Cyberbezpieczeństwo

Aplikacja webowa (Single Page Application) służąca do weryfikacji i utrwalania wiedzy z zakresu bezpieczeństwa w sieci, ochrony danych osobowych (RODO) oraz rozpoznawania zagrożeń cyfrowych (phishing, malware).

## 🚀 O projekcie

Aplikacja ma charakter edukacyjny i pozwala użytkownikowi sprawdzić swoją wiedzę w formie quizu z presją czasu. Projekt został zrealizowany w oparciu o nowoczesne standardy webowe bez użycia ciężkich frameworków, co gwarantuje szybkość działania i pełną responsywność.

## 🛠 Technologie

Projekt został zbudowany przy użyciu:
* **HTML5** (Semantyczna struktura)
* **SCSS / CSS3** (Responsywny design, animacje)
* **JavaScript (Vanilla ES6+)** (Logika aplikacji, DOM manipulation)
* **Google Forms** (Backend do zbierania statystyk)
* **GitHub Pages** (Hosting)
